Getting started

  1. Open any normal web page.
  2. Click the Refract SEO icon in the toolbar (pin it from the puzzle-piece menu if you don't see it).
  3. Overview opens with the page's health score, what to fix first, and whether Google can index the URL.

The number next to a section in the sidebar is how many things in that section need attention. Use ↑ / ↓ to move through sections with the keyboard.

Popup, side panel, full screen

Popup
The quick view. It closes when you click the page.
Side panel
"Open in side panel" docks Refract SEO next to the page for that tab only. Other tabs don't get it. It re-audits automatically when the page navigates.
Full screen
The ⤢ Full screen button (top right) opens Refract SEO in its own tab with room for wide tables. ⧉ Pop out opens it in a separate window you can place beside the site. Both keep auditing the original tab and re-audit when it navigates. Crawling runs here.

Crawling a site

Open full screen (or the side panel), go to Crawl and click Start crawl. The first time, Chrome asks for access to all sites so Refract SEO can fetch other pages; you can decline and keep using everything else.

  • Limits: up to 1,000 pages and 6 clicks deep, same site only, one request at a time with a short pause. A full 1,000-page crawl takes roughly 10–15 minutes.
  • Render JavaScript (optional): loads each page in a background tab so React, Vue or Angular content is seen, and lists pages whose text only exists after JavaScript runs. Much slower (3–5 s per page) and it uses your browser session.
  • Changes since last crawl: new and removed pages, status, indexing and title changes.
  • Polite: obeys the site's robots.txt, sends no cookies, and stops if the server answers 429 or 503 ("slow down").
  • Findings: broken internal links (with the page linking to them), duplicate titles and descriptions, missing titles/descriptions/H1, noindex and canonicalised pages, redirecting links, orphan pages, hreflang without return links, thin pages, slow responses and click depth.
  • Partial crawls are labelled. If the crawl stops at 1,000 pages, Refract SEO says so and does not report orphans, because "nothing links to this page" can't be known until every page has been seen.
  • The last crawl of each site is kept on this computer and shown next time. Export CSV downloads every crawled URL.

Keep the full-screen tab open while it runs. Clicking away from a popup would close it and stop the crawl, which is why crawling isn't offered in the popup.

Connecting data sources

Rankings, keyword volume and difficulty, and backlinks come from a provider you already pay for. In Settings › Connectors, press Connect on the provider, paste its key and press Save & test; then choose which provider handles each job, and your market, under Routing. Keys stay on this computer and are sent only to that provider; each provider's API host is requested as a permission when you save its key.

Keyword research, competitors, backlinks and AI visibility

Keyword research finds keywords around a seed (DataForSEO or Semrush) and keeps a saved list per domain: tag keywords, set a target URL and notes, fetch metrics for keywords added by hand, and import or export CSV (including a Search Console queries export). Save keyword on an Opportunities card adds that query too. Competitors stores the domains you compete with and compares each one's top keywords with yours (Semrush or Ahrefs): gaps are keywords they rank for that are not in your top list; you may still rank lower down. Domain overview shows a domain's estimated organic traffic, ranking keywords, position spread and top pages.

Clusters (in Keyword research) groups saved keywords that share most of their words, free and offline; each cluster is a candidate for one page. Rankings › Add saved keywords tracks them, and live DataForSEO checks also record the SERP features shown.

Backlinks saves a summary snapshot each day you fetch (newest 30 kept per domain) and lists referring domains that are new or no longer listed since the previous snapshot. Load backlinks fetches the individual links (source, anchor, target, follow, first and last seen, lost, and broken and spam signals where the provider supplies them), which costs more per row. Semrush and Ahrefs can't filter lost links on their side, so “lost links only” keeps the lost ones among the links fetched. Link gap lists sites linking to a competitor but not to you; add any of them to Outreach prospects and track status, tags and notes. Refract SEO never contacts anyone. Third-party link indexes are estimates and differ between providers.

AI visibility saves prompts by topic and runs them, through your DataForSEO account, on Google AI Overview, Google AI Mode, ChatGPT (with web search) or Perplexity. Each result says whether the answer cited your domain, mentioned your brand, did neither, came from an engine that returned no sources (so it cannot cite), or the check failed. A failed check is never counted as “not cited”. Results describe one prompt on one engine at one time, not all AI traffic. Edit changes a prompt's topic or engines and keeps its history; new wording or a new market starts a fresh history. Findings appear on Opportunities (competitor cited instead of you, missing comparison page, AI crawler blocked in robots.txt).

More connectors and tools

  • Settings › Spend: every paid request is recorded, with today's totals per provider. Set a daily cap (dollars for DataForSEO, requests for the others) and Refract refuses further paid calls that day.
  • Lighthouse (Speed, and Crawl for many pages): PageSpeed Insights scores, lab metrics, biggest savings and Lighthouse's Agentic Browsing fraction. Free Google API key. Field data in Speed now also splits LCP into server response, load delay, load duration and render delay.
  • Agent readiness (AI search): llms.txt against Lighthouse's rules, Markdown delivery, Content-Signal, ai-catalog.json, API catalog, agent card and WebMCP. Draft standards are labelled as drafts.
  • Trust signals and entities (Content): E-E-A-T checklist, invisible-character check, and Google Cloud Natural Language entities (your key; sends page text only when pressed).
  • Generators: JSON-LD templates (Schema), hreflang sets (Hreflang), sitemap.xml (Crawl), disavow files (Backlinks), comparison-page outlines (Competitors), content briefs (Keyword research), and the audit as Markdown or JSON (Overview, Issues). Retired rich-result types such as FAQPage and HowTo are flagged, never generated.
  • Crawl extras: programmatic template groups (thin or near-duplicate pages), parasite-SEO risk by section, Lighthouse on crawled pages, IndexNow submission.
  • Local geo-grid (Local SEO): your Google Maps position at a grid of points around the business (DataForSEO).
  • Authority (Competitors): free Open PageRank for you and your competitors. Moz can answer backlinks (Domain Authority, spam score, referring domains). Backlinks can also check whether links are still live.
  • Clusters by search results (Keyword research): groups keywords that share Google results, to confirm or merge the word-based clusters.
  • Google Analytics 4 (Search Console): organic landing pages from GA4 (read-only sign-in). IndexNow (Bing Webmaster, Crawl): notify Bing and other engines of changed pages.
  • Domain heritage (Domain): compares the first archived version of the site with today, to spot expired-domain topic changes.

Settings › Research data backs up everything above to one JSON file (never your API keys), restores it, or deletes one domain's research. “How much is kept” lists each retention limit and the space Refract SEO uses.

Search Console & Bing setup

Open Settings › Connectors and press Connect on Google Search Console. Chrome asks you to choose the Google account signed in to your Chrome profile and to allow read-only Search Console access (webmasters.readonly). Chrome keeps the sign-in; Disconnect removes it.

Test user required. While Refract SEO's Google Cloud app is in Testing, your Google account must be listed as a Test user on its OAuth consent screen (Google Cloud Console › APIs & Services › OAuth consent screen › Audience › Test users). If it isn't, Google shows "Access blocked" or "has not completed the Google verification process". Ask the project owner to add you. The account must also have access to the site's property in Search Console.

The Search Console section shows the last 28 days for the page (data lags 2–3 days). Inspect asks Google whether the URL is indexed; it uses Search Console's daily URL Inspection quota, so it runs only when you press it.

Bing: in Bing Webmaster Tools open Settings › API access, generate a key, then Connect Bing Webmaster Tools in Settings › Connectors.

Chrome AI suggestions

On computers that support Chrome's built-in model (Gemini Nano), Refract SEO adds buttons that draft fixes:

  • Suggest titles / descriptions (Overview): three options, each re-measured for length and pixel width.
  • Suggest alt (Images): alt text for an image missing it, from the image itself where the device supports image input, otherwise from its file name and nearby text.
  • Draft JSON-LD (Schema): structured data built only from facts on the page, with any properties it couldn't fill listed.
  • Explain (Issues): a short, plain explanation of why an issue matters.

Everything runs on your device. The first use downloads Chrome's model once (a few GB); progress shows on the button and in Settings. Any suggestion that states a number not found on the page is discarded, so treat what remains as a draft to review, not a finished answer.

Requirements: a recent desktop Chrome (138 or later) on Windows, macOS, Linux or ChromeOS with enough free storage and memory. If your device doesn't qualify, Settings says why and the buttons are hidden.

Bot's eye and View as crawler

Bot's eye
Fetches the current URL as Googlebot, Bingbot, GPTBot, OAI-SearchBot, ClaudeBot and PerplexityBot, without cookies, and shows whether each was served the page, blocked (403/429/503 or a CDN challenge such as Cloudflare's "Just a moment"), or couldn't be verified. It compares the title and word count with what your browser shows, and with robots.txt, so you can spot a firewall blocking a crawler that robots.txt allows.
View as crawler (Tools)
Reloads the current tab with a crawler's User-Agent so you can browse the site as that crawler is served it. A yellow banner shows while it's on; "Back to normal" turns it off. It also ends when you close the tab.

Both change only the User-Agent. Sites that also verify crawlers by IP address may still treat the real crawler differently.

On Google results pages

  • Each organic result gets a position number; Copy results CSV copies position, title, URL and how far down the page each result sits (pixels).
  • The SERP layout panel (bottom left) shows how far down the first organic result is, what's above it (ads, AI Overview, featured snippet, People Also Ask, local pack, videos and more), and whether an AI Overview is shown and which sites it links to. Type your domain to highlight your result, see its position, and check whether the AI Overview cites you. The block names are read from English Google; in other languages only the pixel figures are reliable.
  • Extract People Also Ask opens each question to collect its answer source, follows the questions Google adds, up to three levels deep (100 questions maximum), and exports to CSV.

Both can be turned off in Settings.

Right-click menu

Right-click any page → Refract SEO to open the site in Ahrefs, Semrush, SimilarWeb, Majestic, Moz or the Wayback Machine, run site: searches, highlight nofollow links, or select text and check whether it's duplicated across the web or on the same site.

How scores are calculated

Health
Starts at 100; each "Fix" issue subtracts 12 and each "Check" subtracts 4 (minimum 0). Grades: A ≥ 90, B ≥ 75, C ≥ 50, D below.
AI search readiness
The average of five pillars (crawler access, machine readability, structured data, content & citability, trust). Each pillar is the share of its checks that pass; every check is listed in the AI search view.

No score uses estimated or third-party traffic data.

Troubleshooting

"This page can't be analysed"
Chrome doesn't let extensions read chrome:// pages, the Chrome Web Store or the built-in PDF viewer.
Domain shows "Tranco is rate-limiting"
The free rank service allows few requests per minute. Reopen Domain shortly.
No AI buttons
Check Settings → Chrome built-in AI. "Not supported on this device" means Chrome's hardware requirements aren't met; "Not downloaded yet" means click Download model once.
"Access blocked" / "Error 403: access_denied" when connecting Search Console
Your Google account isn't a test user on Refract SEO's Cloud project. Ask the project owner to add it (see setup).
"No Search Console property covers this URL"
The signed-in account can't see a property for this site. Add the account as a user of the property in Search Console, or sign in with one that can.
Crawl stopped early
The status line says why: the 1,000-page limit, the depth limit, the server asking us to slow down, or you pressed Stop.
INP shows "no interactions yet"
INP needs a click or key press on the page. Interact with the page, then reopen Refract SEO.
Bot's eye or Crawl asks for access to all sites
They fetch pages outside the current tab, which Chrome only allows with that permission. Declining leaves every other feature working.
